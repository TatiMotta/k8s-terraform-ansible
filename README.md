# Kubernetes + Terraform + Ansible

Laboratório prático de infraestrutura e Kubernetes na AWS utilizando Terraform, Ansible, containerd, kubeadm, Calico e kubectl.

## Tecnologias

- Terraform
- AWS
- EC2
- Ansible
- Linux
- containerd
- Kubernetes
- kubeadm
- kubelet
- kubectl
- Calico
- NGINX

## Arquitetura

O projeto será construído seguindo o fluxo:

Terraform → AWS → EC2 → Ansible → Linux → containerd → Kubernetes → Calico → NGINX
